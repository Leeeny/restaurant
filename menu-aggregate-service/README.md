# Menu Aggregate Service

Предоставляет REST API для получения агрегированных данных о блюдах, отзывах к ним и их рейтингах.
Доступно всем пользователям.

- GET /v1/menu-aggregate/{menuId}?sort={sort}&from={from}&size={size} - получить информацию о блюде с отзывами. Список
  отзывов пагинирован и отсортирован по дате создания (DATE_ASC, DATE_DESC)
- GET /v1/menu-aggregate?category={category}&sort={sort} - получить информацию о блюдах из указанной категории. Блюда
  отсортированы или по алфавиту(AZ, ZA) или по цене (PRICE_ASC, PRICE_DESC) или по дате создания (DATE_ASC, DATE_DESC)
  или по рейтингу (RATE_ASC, RATE_DESC). Информация по каждому блюду включает в себя рейтинг блюда, полученный из Review
  Service

Данные запрашиваются из других сервисов, своей базы у сервиса данных нет.
